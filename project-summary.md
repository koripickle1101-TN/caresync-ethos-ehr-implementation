# Project Summary

## CareSync Ethos

CareSync Ethos is a patient safe EHR implementation framework created by Kori Pickle.

The project focuses on how healthcare leaders can implement a new electronic health record without creating avoidable patient safety risk, increasing provider burnout, or leaving patients behind during digital transformation.

## Portfolio Positioning Statement

Designed a patient safe EHR implementation use case analyzing medication safety, provider burnout, equitable access, workflow reliability, phased rollout strategy, and trust centered digital adoption.

## Resume Project Entry

CareSync Ethos Patient Safe EHR Implementation Framework

Independent Health IT Portfolio Project

Developed a Health IT implementation use case for a regional health care organization transitioning from an outdated charting system to a new EHR.

Analyzed implementation risks related to medication reconciliation, allergy alerts, documentation workflows, provider burnout, patient portal access, digital literacy, and workflow disruption.

Created a phased rollout recommendation using pilot testing, role specific training, super user support, downtime planning, patient access resources, and post launch monitoring.

Built an implementation scorecard to evaluate patient safety, staff adoption, equitable access, workflow reliability, and trust stability during EHR transition.
